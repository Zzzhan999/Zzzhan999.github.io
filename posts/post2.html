JavaScript 实战技巧：写出更优雅的代码

📅 2026-03-15 🕑 阅读约 8 分钟 👤 张佳霖

在前端开发的日常工作中，JavaScript 是我们最常用的工具。今天分享一些我在实践中总结的技巧，帮助你写出更简洁、更高效的代码。

1. 解构赋值的妙用

解构赋值是 ES6 中非常实用的特性，可以让代码更简洁：

// 交换变量
let a = 1, b = 2;
[a, b] = [b, a];

// 函数参数解构
function greet({ name, age }) {
    console.log(`${name} is ${age} years old`);
}

// 默认值
const { x = 10, y = 20 } = {};

2. 可选链操作符

可选链 ?. 可以安全地访问深层嵌套的属性，避免报错：

// 传统写法
const city = user && user.address && user.address.city;

// 可选链
const city = user?.address?.city;

3. 数组的实用方法

掌握这些数组方法能让你的数据处理更加高效：

const numbers = [1, 2, 3, 4, 5];

// reduce 求和
const sum = numbers.reduce((acc, cur) => acc + cur, 0);

// flatMap 扁平化
const nested = [[1,2], [3,4]];
const flat = nested.flatMap(arr => arr);

// at 获取末尾元素
const last = numbers.at(-1); // 5
"代码是写给人看的，顺便让机器执行。" —— Harold Abelson

4. async/await 错误处理

使用 try-catch 配合 async/await，让异步代码的错误处理更优雅：

async function fetchData() {
    try {
        const res = await fetch('/api/data');
        const data = await res.json();
        return data;
    } catch (error) {
        console.error('请求失败:', error);
        return null;
    }
}

总结

JavaScript 的世界博大精深，每天都有新的特性和最佳实践出现。保持学习的热情，多写多练，你也能写出优雅高效的代码。
